# Хронос

Автономное браузерное приложение для подготовки и проведения хронологических диктантов. Данные преподавателя хранятся только в IndexedDB браузера: сервер, учётная запись и облачная база не нужны.

## Локальный запуск

Нужен Node.js 22 или новее.

```bash
npm install
npm run dev
```

Откройте `http://127.0.0.1:3000`. Режим Webpack используется намеренно: он надёжно работает и при кириллическом пути к папке проекта в Windows.

```bash
npm test
npm run typecheck
npm run build
```

Статическая версия появляется в папке `out/`; её можно открыть любым статическим HTTP-сервером.

## Данные и резервное копирование

Сценарии, события, настройки и история показов сохраняются в IndexedDB с версионированной схемой `chronos`. Обычное обновление приложения их не удаляет.

На странице «Сценарии» доступны:

- «Экспорт» и «Импорт» — отдельные сценарии;
- «Резервная копия» — единый JSON со всеми пользовательскими сценариями и историей;
- «Восстановить» — предварительный просмотр резервной копии и выбор: объединить данные или заменить текущие.

Перед очисткой данных браузера экспортируйте резервную копию. Старые данные PostgreSQL намеренно не считываются автоматически: для однократного переноса экспортируйте сценарии из прежнего приложения в JSON и импортируйте их через экран «Сценарии».

## GitHub Pages

1. Создайте репозиторий GitHub и отправьте в него проект в ветку `main`.
2. В настройках репозитория включите **Pages → GitHub Actions**.
3. Push в `main` запустит `.github/workflows/deploy-pages.yml`.

По умолчанию workflow собирает сайт в подпапке с именем репозитория. Для собственного домена создайте переменную репозитория `BASE_PATH` со значением пустой строки. Публикация выполняет проверку типов, тесты и статическую сборку до загрузки артефакта.

## Офлайн-режим

После первой полной загрузки браузер устанавливает Service Worker. Установите приложение через меню браузера («Установить приложение»), затем откройте его один раз при подключении к сети. После этого сценарии, библиотека и страницы приложения доступны без сети; пользовательские данные по-прежнему берутся из IndexedDB, а не из кэша.

Для проверки: откройте приложение, создайте сценарий, дождитесь статуса «изменения сохранены», в DevTools включите Offline, перезагрузите страницу и снова откройте сценарий.
