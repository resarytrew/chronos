# Хронос

Автономное браузерное приложение для подготовки и проведения занятий по истории на электронной доске. Дизайн и статическая публикация на GitHub Pages сохранены. Материалы и история хранятся в IndexedDB браузера; сервер и учётная запись не нужны.

## Возможности

- Хронологический диктант: направления дата ↔ событие, автопоказ и ручное управление, варианты А/Б.
- Изучение дат: откройте список с закрытыми датами прямо из сценария или библиотеки. Доступны хронологический и перемешанный порядок, раскрытие по одному, скрытие дат и крупный шрифт. В редакторе используется текущая выборка; режим не изменяет настройки диктанта и не записывает самостоятельное изучение как проведённый урок.
- Хронологическая последовательность: учитель задаёт правильный порядок 3–8 карточек, ученики перемещают их у доски стрелками или перетаскиванием.
- Вопрос — ответ, выбор одного из 2–4 вариантов, задания с историческими изображениями. Проверка и открытие пояснений выполняются отдельной кнопкой.
- Поиск по содержимому, фильтры по классу, разделу и типу занятия, избранное и недавно открытые наборы.
- Предпросмотр, крупные кнопки доски, клавиатура и пульт, шторка, автоматическая пауза при скрытии вкладки.
- Восстановление незавершённого показа с паузы. История сохраняет снимок заданий и различает завершённые и прерванные занятия.
- Печать заданий и отдельного ключа ответов, включая сохранение в PDF через браузер.

Каждый набор содержит один тип заданий. Приложение не собирает индивидуальные оценки и профили учеников.

## Локальный запуск

Нужен Node.js 22 или новее.

```bash
npm install
npm run dev
```

Откройте `http://127.0.0.1:3000`. Режим Webpack используется намеренно: он надёжно работает и при кириллическом пути к папке проекта в Windows.

```bash
npm test
npm run typecheck
npm run lint
npm run build
```

Статическая версия появляется в папке `out/`. `npm start` запускает её на http://127.0.0.1:4173/. Для проверки варианта GitHub Pages соберите с `NEXT_PUBLIC_BASE_PATH=/chronos` и откройте http://127.0.0.1:4173/chronos/.

Для браузерных проверок: `npx playwright install chromium`, затем сборка с `NEXT_PUBLIC_BASE_PATH=/chronos` и `npm run test:e2e`. Тесты используют только локальный статический сервер и отдельные профили браузера. Проверяют полный урок, офлайн-восстановление, перенос изображения в чистый профиль, отложенное обновление, ошибку записи, сенсорные цели и разрешения 1920×1080, 1366×768 и 1024×768.

## Данные и резервное копирование

Наборы, настройки, изображения, история и незавершённый показ сохраняются в версионированной базе `chronos`. Схема v3 обновляет старую базу без удаления событий; старые наборы становятся диктантами. Полные копии и файлы наборов используют формат v2, импорт прежних JSON и полных копий v1 поддерживается.

На странице «Сценарии» доступны:

- «Экспорт» и «Импорт» — наборы вместе с изображениями;
- «Резервная копия» — единый JSON с материалами, изображениями, настройками, историей и незавершённым показом;
- «Восстановить» — предварительный просмотр резервной копии и выбор: объединить данные или заменить текущие.

Перед очисткой данных браузера экспортируйте резервную копию. Старые данные PostgreSQL намеренно не считываются автоматически: для однократного переноса экспортируйте сценарии из прежнего приложения в JSON и импортируйте их через экран «Сценарии».

Импорт проверяет весь файл до записи. При объединении совпадающие идентификаторы переназначаются вместе со ссылками истории и изображений; неизвестные версии отклоняются. Изображения JPEG/PNG/WebP до 12 МБ уменьшаются до 1600 px по длинной стороне. Данные остаются на этом компьютере, пока учитель сам не экспортирует файл. Браузер или очистка профиля могут удалить локальные данные: храните копию отдельно. Дата экспорта означает подготовку скачивания; проверьте, что файл действительно сохранён.

## GitHub Pages

1. Создайте репозиторий GitHub и отправьте в него проект в ветку `main`.
2. В настройках репозитория включите **Pages → GitHub Actions**.
3. Push в `main` запустит `.github/workflows/deploy-pages.yml`.

Workflow собирает сайт в подпапке с именем репозитория (для этого проекта — `/chronos/`). Публикация выполняет проверку типов, lint, тесты, статическую сборку и браузерные проверки до загрузки артефакта. В окружении `github-pages` ветка `main` должна быть разрешена в Deployment branches and tags. Источник Pages — GitHub Actions.

## Офлайн-режим

Сборка создаёт список всех страниц и ресурсов приложения. Дождитесь статуса «Готово к работе без интернета»: он появляется только после успешной подготовки всего пакета. Установка PWA через меню браузера необязательна. Изображения и пользовательские материалы берутся из IndexedDB. Если пакет не удалось скачать, статус готовности не показывается.

Новая версия ожидает команды «Установить обновление». Кнопка доступна вне показа; урок самопроизвольно не перезагружается. Обновление не удаляет IndexedDB. После перезагрузки незавершённый урок предлагается продолжить с паузы.

Для проверки: откройте приложение, создайте сценарий, дождитесь статуса «изменения сохранены», в DevTools включите Offline, перезагрузите страницу и снова откройте сценарий.

Перед использованием всем классом нужна ручная проверка на реальной электронной доске: сенсорный ввод, пульт, читаемость с последней парты, полноэкранный режим, звук и запрет засыпания зависят от оборудования и браузера.
